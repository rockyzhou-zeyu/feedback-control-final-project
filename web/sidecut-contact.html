What A Sidecut-Contact Model Would Look Like

Instead of using one effective curvature relation, a sidecut-contact model resolves how the shaped board edge engages the snow, how contact length changes with edge angle and load, and how that geometry produces a carved turn radius.

What Changes Relative To The Current Curvature Law

Feature Current Page Sidecut-Contact Upgrade
Turn geometry `kappa` comes from effective edge angle and speed `kappa` emerges from sidecut radius, edge angle, and real contact length
Snow interaction One grip coefficient Edge penetration, contact pressure, and possible local slip
Board shape Implicitly hidden Explicit nose, waist, tail, and sidecut geometry
Failure modes Grip loss patch or disturbance Partial washout, over-engagement, short contact, or nose/tail overload

Core Variables

Sidecut Radius Sets the nominal carved arc of the board geometry itself.
Edge Angle Controls how deeply the edge is presented to the snow.
Normal Load Determines how much of the edge can stay engaged without washing out.
Contact Length The effective edge is shorter than the full board and varies with conditions.

Reasonable First Approximation

A sidecut-contact model often starts from geometry like `R_turn ≈ R_sidecut * cos(beta)` and then adds compliance, load transfer, and slip limits. That is the kind of page-level upgrade this diagram is trying to make visible.

Why This Matters

  • It explains why the same lean can carve differently on hardpack vs softer snow.
  • It gives a path to model nose/tail chatter or partial edge release.
  • It ties board design choices directly to the resulting turn radius.
  • It would make the “low-grip patch” effect physically grounded instead of lumped.

Suggested Build Order

Add sidecut radius Add contact length Add edge penetration Then add slip limits
