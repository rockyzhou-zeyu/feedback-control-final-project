Rigid-Body Upgrade Sketch

What A Fuller Rigid-Body Model Would Add

This page keeps the same snowboarding story but expands the body model from one planar roll segment plus a hip joint into a multi-DOF rigid-body system with roll, pitch, yaw, joint angles, and distributed contact loads.

12-18 Typical State Dimensions
3 Attitude Axes: Roll, Pitch, Yaw
2-4 Contact Patches To Resolve
Higher Modeling And Compute Cost

Rigid-Body Layout

The left sketch shows a side-view body decomposition with pitch and roll-sensitive load transfer. The right sketch shows the top-down yaw and front/rear contact structure that the current planar model intentionally collapses away.

The diagram is illustrative: it shows what we would model next, not a second solver already running in the browser.

Current Model vs Fuller Rigid-Body Model

Category Current Page Rigid-Body Upgrade
Orientation Heading plus a planar lean state `phi` Full 3D attitude with roll, pitch, yaw and angular rates
Body model Lower body + torso with one hip articulation `eta` Multiple linked rigid bodies with knee, ankle, hip, and torso motion
Contact One effective grip scalar Front/rear edge loads, pressure distribution, possible slip at each patch
Terrain interaction Disturbance moments and drag penalties Normal-force redistribution from bumps, pitch, and edge loading
Usefulness Excellent for controller design and class presentation Better for realism, but much more tuning and identification work

Added State Groups

Translational DOFs `x, y, z` and their velocities if vertical motion matters.
Attitude DOFs Roll, pitch, yaw and the three body angular rates.
Joint Coordinates Hip, knee, ankle, or torso segments instead of one lumped hip angle.
Contact States Front/rear edge engagement, slip, and pressure distribution.

What This Would Buy Us

  • Pitch-sensitive loading between nose and tail on steeper terrain.
  • Explicit yaw dynamics instead of treating edge upset as one disturbance channel.
  • Clearer interpretation of how upper-body counter-rotation affects board heading.
  • More faithful recovery behavior when terrain or contact changes asymmetrically.

Why We Did Not Start Here

This class project needs a stable, explainable controller more than a maximum-fidelity rigid-body snow interaction model. The current planar page is the right baseline. This page shows the next realism layer, not a replacement for the baseline.

Good Upgrade Path

Keep current path tracker Add pitch and yaw states Split contact into front/rear Then re-tune control
